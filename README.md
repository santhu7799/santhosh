# Santhosh Events

Static event management website.

## Local preview

Run `py -m http.server 8000` in this folder, then open http://localhost:8000.

## GitHub Pages

Push these files to the root of a repository named `santhosh`. In Settings → Pages, select Deploy from a branch, main, /(root). The site URL will be https://events.onlinevedik.com/.

The enquiry form prepares a WhatsApp message. No submission is stored on a server. Gallery photos are illustrative.
